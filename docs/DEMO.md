# TSUMUGI デモ台本（約2分）

写真を入れる → SAM3 が物体を切り出して数える → 複数のモデルが山鉾や提灯を解説し、合意を示す → キャプションの主張を出典で検証する → Neo4j で影響範囲を見る、の順に見せる。

実測（2026-10-17、Apple M4、SAM3 ローカル、ai&、Neo4j Aura、1920×1080、例の2枚）：

- 主張と画像の観察は約3秒で表示される。
- SAM3 のマスクは画像1が約13〜16秒、画像2が約15〜19秒で届き、そのたびにトーストが出る（例：「SAM3 segmented 42 objects in image 1 locally · 12.7s」）。
- 文化の解説は、書き手 deepseek-v4-pro が約13秒、確認役 glm-5.3（約1.5秒）と qwen3.8-27b（約5秒）が並列で確認し、合計で約20秒で届く。
- 初回解析の完了は約20〜30秒。出典の追加による再評価は約4秒、無効化は約0.5秒。再評価ではセグメンテーションも文化の解説も作り直さない。

ai& の応答時間は呼び出しごとにばらつく。本番前に一度通しで流すこと。

## 事前準備（発表5分前）

1. `npm run up` で一括起動し（本番ビルド込みで約15秒、SAM3 のモデル読み込みに約20秒）、http://127.0.0.1:3000/?present=1 を開く。終了は `npm run down`。
2. `npm run status` で、backend が `ready (ai& key configured)`、`sam3` の行が `"status": "ready"` になっていることを確認する。sam3 が ready でないと、マスク・数・切り抜き・スポットライトが出ない（枠だけになる）。
3. 一度通しで流して、ai&・SAM3・Neo4j の疎通を確認し、「New analysis」でトップに戻しておく。
4. 投影は 1920×1080、ブラウザのズームは100%。**発表モード（Present）** を ON にする。ヘッダーの「Present」ボタン、`P` キー、URL の `?present=1` のどれでも入れる（ブラウザに記憶される）。発表モードでは文字が約1.35倍になり、クレジット・注記・凡例・イベントログ・フッターが隠れる。
5. 表示言語はヘッダーの **Both**（英日併記）。

締めの一言：「翻訳ではなく文脈を紡ぐ。SAM3 が見えるものを切り出し、複数の AI が文化を解説し合い、分かることと、まだ分からないことを、根拠付きで英語と日本語で伝えます。」

## 想定質問

- **文化の解説は正しいのか**：解説はモデルの一般知識で、写真についての証拠としては扱わない（画面に固定の注記を出す）。書き手（`AIAND_CULTURE_MODEL`、既定 deepseek-v4-pro）とは別系統の確認役（`AIAND_REVIEW_MODELS`、既定 glm-5.3 と qwen3.8-27b）が、要約と要点を一文ずつ agree / disagree / unsure で判定する。全員が agree なら「✓ 3/3」、確認役の過半数が disagree ならその文は表示しない、それ以外は「⚠ Models disagree」と訂正を併記する。確認役が応答しなければ「Unchecked」と出し、合意とは書かない。
- **なぜその3モデルなのか**：同じ入力で書き手の候補を比べた（2026-10-17）。deepseek-v4-pro は約14秒で4件の正しい JSON を返し、kimi-k3 は60秒で打ち切り、glm-5.3 は本文が空だった。確認役としては glm-5.3 が約1.5秒、qwen3.8-27b が約5秒、kimi-k3 が約20秒（10秒の打ち切りを超える）だったので、確認役は glm-5.3 と qwen3.8-27b にした。kimi-k3 を使う場合は `AIAND_REVIEW_MODELS` で指定できる。
- **解説が判定に影響しないか**：影響しない。解説は判定・説明・引用のどれにもつながらない（Neo4j でも CulturalNote は ABOUT で観察に、GENERATED_BY・REVIEWED_BY でモデルの実行記録につながるだけ）。
- **なぜ写真の場所はConfirmedにならないのか**：一般的な祭りの説明は、特定の写真の撮影地・撮影年を証明しないため、意図的に保留にしている（`photo_provenance_missing`）。写真2の手書き文字や、Commons 上の撮影年（1905年）もモデルには証拠として渡していない。
- **モデルが引用を捏造したら**：モデルは登録済みの passage ID しか選べず、引用文はサーバーが保存テキストから取り出す。存在しないIDは `invalid_citation` として拒否する。主張と画像の対応付けでも、存在しない observation ID は捨てる。
- **独立検証とは**：キャプションの判定の説明文は DeepSeek が英日で書き、qwen（`AIAND_CHECK_MODEL`）が「英文が根拠に沿っているか」と「日本語が英文に忠実か」を確認する。却下されたとき、または検証できなかったときは、コードで決めた英日の定型文に戻す。
- **Neo4jの役割**：Asset／Region／Observation／Claim／Assessment／Passage／Source／Explanation／CulturalNote／ToolRun を、型付きの関係で revision ごとに保存する。画面の Graph は Neo4j から読み出したもの。出典を無効化するときは、Neo4j で影響範囲をたどり、該当する主張だけを再検証する。
- **SAM3 の数と塗り**：VLM が観察ごとに候補枠と短い英語ラベル（例：paper lanterns）を返し、ローカルの SAM3（facebook/sam3、MPS）がそのラベルで画像を分割する。候補枠の中に大半が入るインスタンスだけを採用し、その数を「37 × paper lanterns」のように出す。枠のない観察に新しい領域を作ることはない。マスクも「候補」であり、文化的な意味や撮影地の証拠にはしない。
- **英日併記**：観察・主張・判定理由・説明・文化の解説は、モデルが英日を同時に出力する。出典の引用は原文が正で、日本語は「参考訳」と明記して表示する。
- **未実装**：URL自動取得、公開デプロイ、写真の来歴検証。

## トラブル時

- 「Needs attention」と表示された場合：**Retry** を押す。直前の検証済み表示は保持される。
- 文化の解説が「No cultural background notes」になり、「Cultural background notes are unavailable」の注記が出た場合：書き手のモデルが応答しなかった。判定と SAM3 の表示には影響しない。Retry するか、`AIAND_CULTURE_MODEL` を変えて `npm run down && npm run up`。
- 合意バッジが「Unchecked」になった場合：確認役が10秒以内に応答しなかった。解説は出るが、合意は主張しない。
- ai& が応答しない場合：`.runtime/last-smoke.json` にある直近のスモーク結果（実出力）を見せ、「ライブ実行結果の記録」と明示して説明する。キャッシュをライブ結果として見せない。
- Graph が「Local snapshot (Neo4j unreachable)」と表示された場合：Neo4j からの読み出しに失敗している。グラフは SQLite に保存した同じ revision のデータから描画している（書き込みに失敗した revision は completed にならない）。
- 解析が75秒を超えるとfailedになる。サーバー再起動中のジョブもfailedとなり、Retryで再開できる。
- SAM3 が起動しない・間に合わない場合：解析は止まらず、枠だけが表示され「画像Nのセグメンテーションを利用できなかった」と注記が出る。スポットライトは枠の範囲で動く。`npm run logs` の sam3.log を確認する。
